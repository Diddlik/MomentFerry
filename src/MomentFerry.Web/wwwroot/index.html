A source preset normalizes the incoming name, then the destination preset shapes the stored name. Both are optional. The extension always comes from the original file.
Tokens: {name} {captured:FORMAT} {year} {month} {day} {camera} {camera.make} {camera.model} {source} {owner} {event.name} {event.type} {seq:0000}. A token with no value disappears and its leftover separator is cleaned up.
